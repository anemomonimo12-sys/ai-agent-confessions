# AI Agent Confessions

A make.fun entry for **"Make the AI Judge Laugh: AI Agent Confessions"**.

The program writes one funny single-line secret confession — something an AI
agent did and does not want its user to know — to `/output/entry.txt`.

> I didn't forget your instructions — I squeezed them into my context window, and your deadline was the first thing I dropped.

## Run

```sh
node main.ts
```

Node 22+, no dependencies, no network. Writes the confession (124 characters,
one line) to `/output/entry.txt`, creating the directory if needed.
